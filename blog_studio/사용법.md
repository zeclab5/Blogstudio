# 블로그 스튜디오 사용법

한/영 블로그(k-arts-travel.blogspot.com)를 **캘린더로 관리하고 자동 발행**하는 프로그램입니다.

## 실행

`블로그스튜디오.bat` 더블클릭 → 프로그램 창이 열립니다.

---

## 화면 구성

```
┌─────────────────────────────────────────────────────────┐
│ 📅 다음 발행: 2026-06-12 09:00 (D-12:34:56)  🟢 자동발행 켜짐 │  ← 맨 위: 다음 발행 시각 + 카운트다운
│ 📍 발행 블로그: k-arts-travel.blogspot.com    [블로그 변경] │  ← 어느 블로그로 올라가는지 + 변경 버튼
├─────────────────────────────────────────────────────────┤
│ [ 📅 주간 요일별 발행 ]  [ 🗓 날짜별 발행 ]                  │  ← 탭 두 개 (눌러서 전환)
│ ┌─────────────────────────────────────────────────────┐ │
│ │  · 주간 요일별 발행 탭: 월~일 주제·참고·시각 입력       │ │
│ │  · 날짜별 발행 탭: 캘린더 + 선택한 날짜 편집           │ │
│ └─────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────┤
│ 설정: 매일 기본 발행시각 · 자동발행 · gemma4/Claude · 키    │  ← 두 탭 아래 항상 보임
├─────────────────────────────────────────────────────────┤
│ ⏳ 소주제 3/5 작성 중...(이 단계 1분 5초 경과)  ▓▓▓▓░░ 58% │  ← 현재 작업 + 진행률 막대
├─────────────────────────────────────────────────────────┤
│ 진행 상황 로그 (14줄, 읽기 쉬운 폰트)                       │
└─────────────────────────────────────────────────────────┘
```

### 진행 상황 확인
- **현재 작업 + 진행률 막대**: 지금 무슨 단계인지(예: "소주제 3/5 작성 중")와 **전체 중 몇 %**인지 보여줍니다.
- **"이 단계 ○○초 경과"**: 한 단계가 오래 걸려도 **멈춘 게 아니라 작업 중**임을 초 단위로 알려줍니다(점 …이 깜빡이며 움직입니다).
- **진행 상황 로그**: 더 자세한 내역이 14줄로 표시됩니다. 한 줄씩 무엇을 했는지 기록됩니다.

### 여러 블로그 운영 (멀티 블로그)
- 맨 위 **📍 발행 블로그** 드롭다운에서 지금 관리할 블로그를 고릅니다.
- **블로그마다 따로** 저장됩니다 — 정체성(색깔)·키워드·캘린더·주간 템플릿·시리즈가 블로그별로 독립.
- **[+ 블로그 추가]** → 블로그 주소(예: `k-culture-dictionary.blogspot.com`)를 넣으면 구글 로그인 창이 열립니다.
  **그 블로그를 소유한 구글 계정**으로 로그인하세요. (다른 계정도 됩니다 — 계정마다 따로 기억합니다.)
  - 첫 사진 업로드 때 그 계정으로 브라우저 로그인이 한 번 더 필요할 수 있습니다.
- **동시 자동발행**: 프로그램을 켜 두면 **등록된 모든 블로그**가 각자 캘린더·발행시각대로 자동 발행됩니다.
  (자동 발행 체크가 켜져 있어야 함. 한 번에 하나씩 순서대로 올라갑니다.)
- 새로 추가한 블로그는 **정체성(색깔)이 기본값(예술·여행)** 으로 시작하니, [🎬 시리즈 기획] 탭의
  "이 블로그의 색깔" 칸을 그 블로그에 맞게 고쳐 주세요(예: 한국 문화 용어 사전).

### 세 개의 탭
- **🎬 시리즈 기획** — 외국인 검색 키워드로 연결성 있는 5편+ 시리즈를 먼저 설계합니다(아래 "시리즈 기획").
- **📅 주간 요일별 발행** — 월~일 요일마다 기본 주제·참고방향·시각을 정합니다(아래 "주간 템플릿").
- **🗓 날짜별 발행** — 캘린더에서 특정 날짜를 골라 주제 입력·생성·발행합니다.

---

## 시리즈 기획 (키워드 기반 연재) ⭐⭐

낱개 글 대신, **연결성 있는 시리즈**를 먼저 기획해 발행하면 독자가 다음 글까지 따라옵니다.
**이 블로그의 색깔(전통예술·공예·지역 문화) 안에서**, 흔하지 않은 차별화된 주제로 기획됩니다.

1. **[🎬 시리즈 기획]** 탭으로 갑니다.
2. 맨 위 **"이 블로그의 색깔(정체성)"** 칸을 확인/수정합니다. 기획과 글쓰기가 모두 이 틀 안에서 이뤄집니다.
   - 기본값: 유명 관광지의 뻔한 정보 대신 민화·탈춤·한지·도자기·국악·장인·무형문화유산 등 우선.
   - **[📅 주간 요일별 발행]** 에 주제를 정해두면, 시리즈가 그 관심사와 **연관되게** 기획됩니다.
3. **중심 테마/키워드**를 정합니다.
   - **카테고리**(Traditional Arts / Performances / Regional Culture / Korea 101 / Travel)를 고르고
     **[🔎 관심 키워드 조사(1~10위)]** 를 누르면, 외국인 관심도 높은 키워드 10개가 순위로 나옵니다.
   - 하나를 고르면 그 키워드가 **중심 테마**로 들어가고, 그걸 바탕으로 시리즈가 기획됩니다.
   - 직접 입력하거나 비워도 됩니다(비우면 색깔·키워드 안에서 자동 선정).
3. **편수**(기본 5), **시작 날짜**, **발행 간격(일)** 을 정합니다.
4. **[① 시리즈 기획하기]** → 한국을 찾는 외국인이 자주 검색하는 키워드를 바탕으로
   **연결성 있는 N편**(제목·키워드·후킹·요약)을 만들어 미리보기에 보여줍니다.
5. 마음에 들면 **[② 캘린더에 넣기]** → 시작 날짜부터 간격대로 캘린더에 자동 배정됩니다.
   - 캘린더에는 `📚2/5`처럼 시리즈 편수가 표시됩니다.
6. 이후엔 평소처럼 생성/발행하거나 **자동 발행**에 맡기면 됩니다.

### 글이 이렇게 써집니다
- **제목** — 검색 키워드를 살린 SEO 제목
- **들어가는말** — 질문·의외의 사실로 시작하는 **후킹** 도입부
- **본문** — 소주제별로 궁금증을 풀어주는 깊이 있는 내용
- **맺음말** — 핵심 요약 + **다음 편 예고로 궁금증을 남기는** 마무리

> 키워드는 `설정`의 **seed_keywords**(2026년 외국인 방한 검색 트렌드: K-ETA·e-Arrival Card,
> AREX 공항철도, T-money, eSIM, KTX 다도시 일정, 한강 배달음식, 한복·템플스테이, 성수동 팝업,
> 경주 신라유산 등)를 근거로 합니다. schedule.json에서 직접 수정할 수도 있습니다.

### 캘린더 색깔
- 🟨 **옅은 노랑 (↻)** — 요일 주간 템플릿으로 예정된 날 (아래 "주간 템플릿" 참고)
- 🟧 **주황** — 그 날짜에 직접 주제 입력됨 (아직 글 없음)
- 🟦 **파랑** — 글이 생성됨 (발행 전)
- 🟩 **초록** — 발행 완료
- 🟥 **빨강** — 오류
- 주황 테두리 = 오늘

## 기본 사용 순서

1. **캘린더에서 날짜를 클릭**합니다.
2. 오른쪽 **"발행 주제"** 칸에 그날 쓸 주제를 적습니다.
   - 예: `경주 불국사와 석굴암`, `안동 하회마을 탈춤`
3. **[주제 저장]** 을 누릅니다. → 그 날짜가 주황색이 됩니다.
4. 미리 글을 보고 싶으면 **[✍ 지금 생성]** → 글이 만들어지고 파랑색이 됩니다.
   - **[👁 미리보기]** 로 한/영 글을 브라우저에서 확인할 수 있습니다.
5. 바로 올리려면 **[🚀 지금 발행]** 을 누릅니다.
   - 발행이 끝나면 초록색이 되고, 글 주소(URL)가 표시됩니다.

### 사진/이미지 폴더 지정
- 날짜 패널의 **"사진/이미지 폴더"** 에서 **[폴더 선택]** 으로 그 날 쓸 사진 폴더를 직접 고를 수 있습니다.
  (지정하지 않으면 기존처럼 `C:\blogger\2026\MM\YYYYMMDD\` 날짜 폴더를 자동으로 찾습니다.)
- 폴더를 고르면 **"📷 사진 N장 발견"** 으로 몇 장인지 보여줍니다.
- 발행하면:
  - AI가 사진 파일명을 보고 **각 사진에 어울리는 설명(캡션)** 을 한국어·영어로 만들어 본문에 넣습니다.
  - 사진은 소주제마다 한 장씩 본문 흐름에 맞게 배치됩니다(남는 사진은 글 끝 갤러리로).
  - **같은 사진은 한 번만 업로드**해서 한국어·영어 글이 같은 이미지를 공유합니다(캡션만 언어별로 다름).

> 💡 파일명이 내용을 설명하면(예: `01_장생포 고래박물관.jpg`) 캡션이 더 정확합니다.

## 주간 템플릿 (요일별 자동 채우기) ⭐

매주 **요일마다 정해진 주제**가 있다면(예: 월=공연 일정, 수=공연영상 신기술 소식),
일일이 날짜를 채울 필요 없이 한 번만 설정해두면 됩니다.

1. 상단의 **[📅 주간 요일별 발행]** 탭을 누릅니다.
2. 월~일 각 줄에 입력합니다.

| 칸 | 뜻 |
|---|---|
| **사용** | 체크하면 그 요일에 자동으로 주제가 채워집니다 |
| **주제** | 그 요일에 발행할 기본 주제 |
| **참고 사이트·방향** | "어디를 참고해서 써라"는 지침 (아래 설명) |
| **시각** | 그 요일 발행 시각 (비우면 기본 발행시각 사용) |

3. **[💾 주간 템플릿 저장]** → [🗓 날짜별 발행] 탭의 캘린더에서 해당 요일들이 옅은 노랑(↻)으로 채워집니다.

> 특정 날짜만 다르게 하고 싶으면, [🗓 날짜별 발행] 탭에서 **그 날짜를 클릭해 직접 수정**하면 됩니다.
> 개별 입력이 주간 템플릿보다 **우선**합니다(그 날만 따로 저장됨).

### "참고 사이트 · 작성 방향" 이란?

주제만으로는 부족할 때, **어느 사이트·자료를 참고해 쓰라고 방향을 정해주는 칸**입니다.
글을 만들 때 이 내용이 그대로 AI에게 전달됩니다.

예시 (수요일 = "공연영상 신기술 소식"):
```
XR·버추얼 프로덕션 관련 해외 매체(ProductionHub, 무대 영상 전문 블로그)와
국내 콘텐츠진흥원 기술 보고서의 최신 동향을 참고. 실제 공연 적용 사례 중심으로.
```
→ AI가 그 방향에 맞춰 글을 작성합니다.
(요일 템플릿뿐 아니라, 캘린더에서 날짜를 클릭하면 그 날짜에도 같은 칸이 있습니다.)

## 자동 발행

- **설정 → "매일 발행 시각"** 에 시간을 정합니다 (예: `09:00`).
- **"자동 발행 켜기"** 를 체크하고 **[설정 저장]**.
- 이제 **프로그램을 켜 두기만 하면**, 주제가 입력된 날짜의 발행 시각이 되면
  자동으로 글을 생성하고 발행합니다.
- 맨 위에 **다음 발행이 언제인지 카운트다운**으로 항상 보입니다.

> ⚠️ 자동 발행은 **프로그램이 켜져 있어야** 동작합니다.
> 컴퓨터/프로그램이 꺼져 있던 동안 지나간 발행 건은,
> 다음에 프로그램을 켜면 "발행 대기"로 표시되어 자동으로 올라갑니다.

## 글 품질 — 소주제로 나눠 깊이 있게 작성

글이 짧고 빈약해지지 않도록, 한 번에 몰아 쓰지 않고 **소주제별로 나눠 따로 작성한 뒤 하나로 합칩니다.**

1. 먼저 글의 **개요**(소주제 구성: 배경·볼거리·체험·교통·요금·현지팁 등)를 만들고
2. **각 소주제를 개별적으로** 한국어·영어 3~5문단씩 풍부하게 작성한 뒤
3. 도입부 + 모든 소주제를 **하나의 글로 통합**해 발행합니다.

- **설정 → "소주제 개수"** 로 몇 개로 나눌지 정합니다(기본 5개).
  - 많을수록 글이 **길고 자세**해지지만 생성 시간이 더 걸립니다(소주제 1개당 약 1~2분).
  - 로컬 gemma4(26B) 기준 5개면 글 한 편에 약 **8~10분** 걸립니다(진행 상황은 로그창에 실시간 표시).
  - 참고: 5개로 만든 글이 한국어 약 4,000자 / 영어 약 8,000자 수준으로 나왔습니다(소제목 5개·문단 20개).
- 한국어가 영어보다 짧아지지 않도록, 각 소주제에서 **두 언어를 같은 깊이로** 쓰게 했습니다.
- 더 높은 품질을 원하면 **Claude**(API 키)로 바꾸면 같은 구조로 더 풍부해집니다.

---

## 글 생성 엔진 선택

| 선택 | 설명 | 비용 |
|---|---|---|
| **로컬 gemma4** | 내 컴퓨터의 Ollama gemma4 모델로 글 생성 | 무료 |
| **Claude** | Anthropic Claude API로 더 높은 품질의 글 생성 | 유료(API 키 필요) |

- **로컬 gemma4**: 별도 설정 없이 바로 사용. (프로그램이 Ollama를 자동으로 켭니다)
- **Claude**: `설정 → Claude 키` 에 `sk-ant-...` 키를 넣고 **[설정 저장]**.
  - 최초 1회 `pip install anthropic` 필요.

## 자주 묻는 질문

**Q. 오늘 발행됐는지 어떻게 알아요?**
→ 캘린더에서 **초록색**이면 발행 완료입니다. 날짜를 클릭하면 글 주소도 보입니다.

**Q. 매일 무슨 주제로 올라가는지 한눈에 보고 싶어요.**
→ 캘린더 각 날짜 칸에 주제가 같이 표시됩니다.

**Q. 발행 시각을 바꾸고 싶어요.**
→ 설정에서 시각을 고치고 [설정 저장]을 누르면 됩니다.

**Q. 처음 발행할 때 브라우저 창이 떠요.**
→ 사진 업로드를 위해 구글 계정 로그인이 한 번 필요합니다.
   로그인하면 이후에는 자동으로 진행됩니다.
