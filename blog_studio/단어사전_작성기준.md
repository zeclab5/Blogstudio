# 한국 문화 단어 사전 (K-Word Dictionary) — 작성 방법과 기준

> 블로그: **k-culture-dictionary** / 발행: **매주 수요일 07:00** (주간 템플릿 등록 완료, 2026-06-29)
> 한 편 = **단어 1개**. 외국인이 K-드라마·K팝·여행에서 만난 한국 문화 단어의 **뜻과 맥락**을 푸는 글.

---

## 1. 이 시리즈는 무엇인가 (정체성)

- **목표 독자**: 한국에 안 가도 궁금한 사람 — K-콘텐츠 팬, 한국어 입문자, 문화 호기심층.
- **검색 의도**: `"jeong meaning"`, `"what does oppa mean"`, `"nunchi"` 처럼 **"이 말이 무슨 뜻이야?"**.
- **한 줄 정의**: *위키가 주는 '정의'가 아니라, **'겪으면 어떤 느낌이고 왜 한국적인가'**를 주는 사전.*

## 2. Korea 101(토요일)과의 경계 — 겹치면 안 됨

같은 블로그라 키워드가 겹치면 서로 잡아먹습니다. 경계선을 **반드시** 지킬 것:

| | **Korea 101 (토)** | **단어 사전 (수)** |
|---|---|---|
| 단위 | 상황·행동 ("교통카드 쓰는 법") | 단어 1개 ("정") |
| 질문 | **무엇을 하라 (how-to)** | **무슨 뜻이고 왜 그런가 (의미)** |
| 예시 | K-ETA, 결제, 식당 매너 체크리스트 | 정·눈치·오빠·애교 |

- **실용·준비·행동** 주제(비자·교통·결제·"~하는 법") → **101로**.
- **개념·정서·호칭·미감 단어** → **단어 사전으로**.
- 애매하면: *"이건 검색창에 'meaning'을 붙여 찾을 단어인가?"* → 그렇다면 단어 사전.
- 둘은 **서로 링크로 연결**(예: 사전 '회식' → 101 '술자리 매너', 101 '식사 예절' → 사전 '정·눈치'). 프로그램의 관련 글·내부링크 기능이 자동으로 받쳐줌.

## 3. 글 구조 (6단 — 이 순서를 지킬 것)

1. **핵심 요약 (한 줄)** — 검색해 들어온 독자가 첫 줄에서 답을 얻게. *(프로그램이 자동 생성하는 TL;DR 박스 활용)*
2. **직역·어원·발음** — 한자/순우리말 뿌리, 로마자 발음, 글자 그대로의 뜻.
3. **실제 쓰이는 장면 2~3개** — K-드라마/일상에서 이 말이 나오는 구체적 순간. ("회식에서 상사가 ~할 때")
4. **다른 문화와 비교** — 왜 한국적인가. 서양/일본/중국의 비슷한 개념과 **무엇이 다른지**.
5. **직접 보고 경험하는 법** — 이 단어를 실제로 느낄 수 있는 장소·상황·콘텐츠(가능하면 직접 찍은 사진·지도).
6. **관련 단어** — 같은 클러스터의 다른 단어로 연결(내부링크). 저자 한마디로 마무리.

## 4. 작성 기준 — 해야 할 것 / 하지 말 것

**해야 할 것**
- ✅ **첫 100자 안에 답**을 준다(역피라미드).
- ✅ **장면·비유·비교**로 푼다. 추상적 정의보다 "이럴 때 이런 느낌".
- ✅ **1인칭 에디터 관점** 허용 — "내가 한국에서 처음 ~했을 때". (위키는 못 하는 차별점, E-E-A-T)
- ✅ **외국인의 혼란을 직격** — "왜 한국인은 ~할까?"에 답한다.
- ✅ 어원·용례는 **신뢰 가능한 사실**로(네이버 백과 그라운딩·참고 자료 링크 활용).

**하지 말 것**
- ❌ 사전적 정의 나열·백과사전 베끼기(위키와 똑같아지면 진다).
- ❌ "~하는 법" 실용 가이드로 빠지기(그건 Korea 101).
- ❌ 근거 없는 단정(어원·유래를 지어내기). 모르면 "여러 설이 있다"로.
- ❌ 한 글에 여러 단어 욱여넣기. **한 편 = 한 단어**.
- ❌ 인물·감정·인종 추측, 고정관념.

## 5. 단어 선정 기준 + 후보 + 클러스터

**선정 기준**: ① 외국인이 실제로 검색함 ② 위키 정의로는 부족함(번역 난이도↑) ③ 장면·비교·경험으로 풀 수 있음 ④ 클러스터로 엮임.

**클러스터(허브-스포크)** — 같은 클러스터끼리 내부링크로 연결:

- **한국인의 정서·마음**: 정(Jeong) · 눈치(Nunchi) · 한(Han) · 체면(Chemyeon) · 효(Hyo)
- **K-콘텐츠 속 한국어**: 오빠/언니/형/누나(호칭) · 애교(Aegyo)
- **한국인의 생활 방식**: 빨리빨리(Ppalli-ppalli) · 회식(Hoesik)
- **오감으로 경험하는 전통**: 온돌(Ondol) · 사찰음식(Temple Food)

**시작 추천 3편**: ① 눈치(차별화 간판) ② 정(클러스터 허브) ③ 오빠/호칭(검색량 최상).

## 6. 톤·분량·SEO

- **톤**: 친근한 설명체. 팬·입문자 눈높이. 전문용어는 풀어서.
- **분량**: 단어 하나에 집중하되 깊이는 유지(한국어 약 1,500자+/영어 동일 깊이). 너무 짧으면 thin content.
- **제목**: 검색어를 앞에. 예) `Nunchi: The Korean Social Superpower Foreigners Struggle With` / `눈치 뜻 — 말 안 해도 분위기를 읽는 한국식 센스`.
- **한·영 별도 발행** + 언어 링크(기존대로). 영문 글에 한국어 설명이 섞이지 않게.
- 프로그램이 자동 적용하는 것(이미 구현): 핵심 요약·목차·FAQ·관련 글·참고 자료·저자 소개·구조화 데이터.

## 7. 프로그램에서 운영하는 법

- **자동**: 매주 수요일, 주간 템플릿의 `refs`(위 기준 요약 + 후보 리스트)를 바탕으로 LLM이 **후보 중 아직 안 쓴 단어 1개**를 골라 작성. 과거 글 제목 중복 방지 기능이 같은 단어 반복을 막음.
- **특정 단어를 지정하고 싶을 때**: 캘린더에서 해당 **수요일 날짜를 클릭 → 주제란에 단어를 직접 입력**(예: "눈치 (Nunchi)") → 그 단어로 생성. (주간 템플릿보다 날짜별 입력이 우선)
- **클러스터 키우기**: 같은 클러스터 단어를 연달아 발행하면 관련 글·내부링크가 자동으로 묶여 토픽 권위가 쌓임.
- **참고**: 단어 글은 장소가 없을 때가 많아 '위치 지도'는 자동 생략됨(정상). 실용정보 표 대신 FAQ가 핵심(예: "정은 사랑인가요?", "Is it rude to refuse?").
- **이미지(2026-06-29 자동화) — 단어 글은 사진 대신 '단어 카드' 2종**:
  - **① 타이틀 카드(히어로)**: 맨 위. 깔끔한 배경 + 한글·영어 단어 + 한 줄 의미.
  - **② 연관 단어 카드(중간)**: '연결된 단어들' 섹션에. 주제 단어(가운데)에서 연관 단어로 선이 뻗는 **네트워크 그림**(예: 눈치 → 정·기분). 개요의 `related_words`(2~3개)로 생성.
  - 단어 글은 **사진 라이브러리 자동 매칭을 끔**(엉뚱한 이미지 방지). 둘 다 `title_card.py`(맑은 고딕, ComfyUI 불필요). 단어 인식=`K-Word Dictionary`/`단어 사전` 마커. 카드 실패 시 그 자리표시자 제거.
  - 별도 사진을 쓰고 싶으면 그 수요일 날짜에 **사진 폴더를 지정**하면 카드 대신 그 사진을 씀.
