# Korea Arts & Travel 자동 발행 시스템 개발일지

## 시스템 개요

**블로그:** k-arts-travel.blogspot.com  
**목적:** 한/영 bilingual 여행·전통예술 블로그 자동 발행  
**주요 파일:**

| 파일 | 역할 |
|---|---|
| `publish_today.py` | 메인 발행 스크립트 |
| `update_post.py` | 기존 포스트 사진 업데이트 |
| `upload_via_browser.py` | Playwright 브라우저 이미지 업로드 |
| `post_config.json` | 포스트 메타데이터 (제목/슬러그/레이블) |
| `post_en.html` | 영문 본문 |
| `post_ko.html` | 한국어 본문 |
| `발행하기.bat` | 원클릭 실행 배치 파일 |
| `playwright설치.bat` | Playwright 최초 설치용 |

---

## 문제점 및 해결 이력

### 1. 이전 포스트(민화)가 발행되는 문제
**원인:** 자동화 태스크가 `C:\blogger\` 폴더에 접근하지 못해 임시 경로(`outputs\publisher\`)에 파일을 저장. `발행하기.bat`은 `C:\blogger\publisher\`의 이전 민화 파일을 읽어 발행.  
**해결:** Cowork 폴더 연결(`C:\blogger\`) 후 파일을 직접 해당 경로에 저장.

---

### 2. 사진 폴더를 찾지 못하는 문제 (`--20260609` 인식 불가)
**원인:** `find_date_folder()`가 완료 표시(`--`) 없는 폴더명만 탐색.  
**해결:** 후보 경로에 `--{compact}`, `----{compact}`, `--{date_str}` 추가.

```python
candidates = [
    BLOGGER_ROOT / year / month / compact,
    BLOGGER_ROOT / year / month / f"--{compact}",
    BLOGGER_ROOT / year / month / f"----{compact}",
    ...
]
```

---

### 3. 언어 전환 링크 중복 삽입
**원인:** `strip_template_lang_links()`가 `[포스트 URL]` 플레이스홀더 형태만 제거하고, HTML 파일에 이미 실제 URL로 작성된 링크는 제거하지 못함.  
**해결:** 실제 URL 형태(`한국어로 읽기` / `Read in English` 텍스트)도 정규식으로 제거.

```python
html = re.sub(
    r'<p[^>]*>\s*[🇰🇷🇺🇸]\s*<a\s[^>]*>(?:한국어로 읽기|Read in English)</a>\s*</p>\s*',
    '', html, flags=re.DOTALL
)
```

---

### 4. URL 끝에 숫자 붙는 문제 (`_01078696513.html`)
**원인:** 비슷한 슬러그의 포스트가 짧은 간격으로 연속 발행될 때 Blogger가 타임스탬프를 자동 추가.  
**해결:**
- 슬러그 규칙 변경: `-en` / `-ko` 접미사로 명확히 구분
- 발행 간 대기 시간 2초 → 4초
- URL 불일치 감지 시 삭제 후 재발행하는 retry 로직 추가

---

### 5. 사진이 포스트에 나타나지 않는 문제 (base64)
**원인:** Blogger API가 보안 정책상 `data:image/jpeg;base64,...` 형식의 인라인 이미지를 HTML에서 자동 제거.  
**해결:** 외부 CDN URL 방식으로 전환 (이미지를 외부에 올린 뒤 URL만 삽입).

---

### 6. Picasa API 404 오류
**원인:** Google이 Picasa Web Albums API(`picasaweb.google.com`)를 2026년 완전 종료.  
**경과:**
- imgbb.com API로 우회 시도
- 사용자 요청으로 외부 서비스 의존 없이 구글 자체 CDN 사용 방향으로 전환

**구글 내 대안 검토:**

| 방법 | 결론 |
|---|---|
| Picasa API | 완전 종료, 404 |
| Google Photos API | 공개 직접 링크 제공 안 함 |
| Google Drive | 핫링크 트래픽 제한 → 대용량 블로그에 불안정 (이미지 깨짐) |
| Google Cloud Storage | 유료 |
| Blogger API v3 | 이미지 업로드 엔드포인트 없음 |

**최종 해결:** Playwright로 Blogger 웹 에디터를 자동 조작해 이미지를 직접 업로드 → `lh3.googleusercontent.com` URL 획득 (Blogger가 살아있는 한 영구 보존).

---

### 7. 한/영 사진 캡션 언어 불일치
**원인:** 초기 `inject_photos()`에 `lang` 파라미터가 없어 영문 alt 텍스트가 한국어 포스트에도 삽입됨.  
**해결:**
- `inject_photos(html, photo_uris, lang="en"|"ko")` 파라미터 추가
- `post_en.html`에는 영문 alt, `post_ko.html`에는 한국어 alt 작성
- 플레이스홀더 교체 시 각 HTML 파일의 alt 텍스트를 그대로 사용
- 갤러리 잔여 사진: 영문 `"Photo N"`, 한국어 파일명으로 자동 구분
- `update_post.py`에도 `lang_ok()` 검증 추가 (언어 불일치 시 자동 교체)

---

### 8. `mark_done()` 폴더명 이중 접두사 (`----YYYYMMDD`)
**원인:** 이미 `--`로 시작하는 폴더에 다시 `--`를 붙여 `----20260609`가 생성됨.  
**해결:** `startswith("--")` 체크 후 이미 완료된 폴더는 건너뜀.

```python
if folder.name.startswith("--"):
    return
```

---

### 9. HTTP 헤더 한글 인코딩 오류
**원인:** Picasa 업로드 시 `Slug` 헤더에 한글 파일명을 넣으면 `latin-1 codec` 오류 발생. HTTP 헤더는 ASCII만 허용.  
**해결:** `path.stem.encode('ascii', 'ignore').decode('ascii')` 로 ASCII 변환 (Playwright 방식으로 전환 후 해당 없음).

---

### 10. Playwright 403 오류
**원인:** Playwright의 Chromium을 Google이 봇으로 감지하거나, 세션 없는 상태에서 에디터 URL(`/blog/post/edit/new/{blog_id}`)에 직접 접근.  
**해결:**
- 시스템 Chrome 우선 사용 (`channel="chrome"`) → 없으면 Chromium 폴백
- 직접 접근 대신 단계적 진입: `blogger.com 홈` → `블로그 대시보드` → `새 글 에디터`
- 최초 1회 로그인 후 `browser_profile/` 폴더에 세션 저장, 이후 재사용

---

## 현재 이미지 업로드 흐름

```
원본 사진 (예: 4MB, 4000px JPEG)
    ↓ compress_for_seo()
SEO 최적화 임시 파일
  - 최대 너비: 1200px (LANCZOS 리샘플링)
  - JPEG 품질: 82
  - EXIF 완전 제거 (방향 적용 후 드롭)
    ↓ Playwright → Blogger 웹 에디터
lh3.googleusercontent.com URL 반환
    ↓ 임시 파일 자동 삭제 / 원본 보존
    ↓ inject_photos() — IMAGE_N 플레이스홀더 교체
Blogger API로 포스트 발행
```

---

## 사진 캡션 언어 처리 규칙

| 구분 | IMAGE_N 플레이스홀더 | 갤러리 잔여 사진 |
|---|---|---|
| 영문 포스트 | `post_en.html`의 영문 alt 그대로 | `"Photo 1"`, `"Photo 2"` ... |
| 한국어 포스트 | `post_ko.html`의 한국어 alt 그대로 | 파일명(언더바 → 공백) |

## 실행 전 준비사항

### 최초 1회
```
playwright설치.bat 실행
  → pip install playwright pillow
  → playwright install chromium
```

### 매일 발행
```
발행하기.bat 실행
  → 최초: 브라우저에서 구글 계정 로그인
  → 이후: 저장된 세션 자동 재사용
```

```

│   ├── post_config.json

│   ├── client_secrets.json
│   ├── token.json
│   ├── blog_id.txt

│   ├── 발행하기.bat
│   └── playwright설치.bat
└── 2026\
    └── 06\
        └── --20260609\      ← 완료된 날짜 폴더 (-- 접두사)
            ├── 01_장생포 고래박물관.jpg
            └── ...
```

## 잔여 이슈 / 향후 확인 필요

- **Playwright 셀렉터 안정성:** Blogger 에디터 UI가 업데이트될 경우 이미지 삽입 버튼 셀렉터(`button[aria-label*="image" i]` 등) 재확인 필요
- **403 재발 가능성:** Google 계정 세션 만료 시 `browser_profile/` 삭제 후 재로그인 필요
- **슬러그 충돌:** 같은 날 포스트를 두 번 이상 발행하면 URL 재충돌 가능 — 기존 포스트 삭제 후 재발행 권장
